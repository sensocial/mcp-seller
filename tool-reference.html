Tool reference

The connector provides 48 tools: 33 are read-only and 15 can write. Every write tool returns a preview by default and applies a change only when confirmation is set.

Read-only tools are marked readOnlyHint in the protocol, so a compliant client can run them without prompting. Write tools are marked readOnlyHint: false; the seven that change or replace something already there (campaign status, store listings, order designs, a fulfillment order, a custom domain, a blog post) are also marked destructiveHint, so a compliant client prompts before applying them. The server does not enforce a separate human confirmation round trip; a client configured for automatic approval can send confirmation on its first call.

Every tool is filtered server-side to the seller account authorised for the connection. References to “your” data below mean data filtered by the backend, not by the assistant.

Sales & analytics — 5 tools, all read

ToolWhat it returns
Sales overviewHeadline KPIs for a window: paid orders, items, sales, profit, AOV, visits, funnel events, refunds, plus live balance; optionally compared with the window before it
Sales chartDaily time series for sales, visits and each funnel step
Sales breakdownSales, orders and profit split by one dimension: country, device, store, product, or ads campaign, source or medium
Campaign salesYour best-selling campaigns for a window, and totals for every campaign whose title contains a keyword
Contest SenPointsYour points in the latest SenPrints contest, its reward tiers and how far the next tier is

Your campaigns can be cross-listed on the marketplace and on stores you do not own. Those rows are combined in an anonymous “Other” bucket. Your figures are included, but the other party’s store identity is not returned.

Orders — 9 tools, 3 write

ToolWhat it does
Search ordersYour store orders or fulfillment orders, filtered by status, payment, fulfilment, customer email, order number, store, campaign or date
Get orderOne order by id or order number, with its line items
Get order visit logThe storefront journey that ended in one of your orders: pages viewed, clicks, where the session stopped
Search cancel requestsCancel requests on your orders
Search abandoned ordersUnpaid carts, with what the buyer was about to pay and which recovery messages were sent
Search orders waiting for a designOrders whose lines wait in designing because a custom campaign launched without print files

The fulfillment-order preview resolves each line against the catalog and reports the variant, an indicative base cost, and every blocking error or warning before anything is created.

Campaigns — 9 tools, 7 write

ToolWhat it does
Search campaignsYour campaigns, filtered by status, keyword, store, type or created date
Get campaignOne campaign by id or slug, including its pricing and cost fields
Set campaign status WriteWrites. Switches campaigns between active and inactive
Take campaigns off a collection or store WriteWrites. Removes the listing links; the campaigns stay active and keep their URL
Create custom campaigns WriteWrites. Up to 20 campaigns per call from your own mockup photos
Create all-over-print campaigns WriteWrites. Up to 20 campaigns per call, one design printed over the whole product
Create regular campaigns WriteWrites. Up to 20 campaigns per call, print designs placed on products the way the dashboard editor places them
Create an express template WriteWrites. The product set (templates, prices, colors) that express campaigns sell
Create express campaigns WriteWrites. Up to 20 campaigns per call from one express template, one design each

Without confirmation, every campaign write returns a preview listing exactly what would be created or changed, and anything refused because it does not belong to you or fails a check (price range, print size, trademark). Batch creation sends the preview’s hash back on confirmation, so a confirmed call cannot create something different from what was previewed. No tool deletes a campaign or changes campaigns in draft, reviewing or blocked states.

Customers — 1 tool, read

ToolWhat it returns
Search customersBuyers who purchased from your stores, by name or email, store, country or order count

This tool returns the same columns shown in the dashboard /customers list: name, email, phone, country, city, state, store, and the number and value of orders placed with you. Buyer credentials, payment-processor IDs and platform-wide totals are never returned. See Data & security.

Money — 5 tools, all read

ToolWhat it returns
Balance summaryYour current balance, billing totals grouped by type and status, plus a payout breakdown
Search transactionsSales, commissions, payouts, fees, refunds and topups, including your payout history
Get payoutOne payout by id
Search refundsPayment-gateway refunds on your orders
Search topupsYour topup transactions

Amounts are in USD, the platform settlement currency. Gateway response traces, payout signatures and raw topup payloads are removed before a response is returned.

No tool requests a payout, transfers money or changes a payment method. The only charge a tool can cause is the extra print cost of a multi-print-space product when you approve an order’s designs, deducted from your SenPrints balance as it is on the dashboard.

Blog & SEO — 4 tools, 1 writes

ToolWhat it does
Search blog postsYour storefront posts, by store, keyword, category or published state
Get blog postOne post including its full HTML body
Search blog categoriesYour categories, so a post can be filed correctly
Create or update a blog post WriteWrites, and publishes to your public storefront

Without confirmation, Create or update a blog post previews whether it would create or update a post, the resolved URL slug, target store, published state and body size. On update, it retains the existing slug unless you provide a new one. All HTML is sanitised when saved, so scripts and event handlers are removed from submitted content.
